Privacy Policy

gDriveSync · last updated 2026-10-04

What the app does

gDriveSync is a personal desktop utility for Windows. It copies folders chosen by the user from their PC to the /gDriveSync folder of the user's own Google Drive and restores them back on request.

Google user data accessed

With the user's consent the app requests the Google Drive scope (https://www.googleapis.com/auth/drive). It uses it only to create, update, list, download and delete files inside the /gDriveSync folder and to read storage quota. Files outside that folder are not read or modified.

Storage and sharing

  • The OAuth token is stored only on the user's computer, in a local configuration file.
  • The app has no servers. No data, token or telemetry is sent to the developer or to any third party.
  • File contents travel only between the user's PC and the user's Google Drive.
  • Google user data is not sold, used for advertising, or used to train AI models.

Revoking access

Access can be revoked at any time in the app ("Disconnect") and at myaccount.google.com/permissions. Uninstalling the app removes the locally stored token.

Limited Use

gDriveSync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact
