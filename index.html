gDriveSync

Personal Windows backup utility.

gDriveSync mirrors folders selected by the user from their own Windows PC to the /gDriveSync folder of their own Google Drive, and restores them on demand. It is a personal, non-commercial tool used by its author; it runs entirely on the user's computer and has no servers.

Google Drive access is used only to upload, update, list and download files inside the /gDriveSync folder.
